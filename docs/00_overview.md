# 00. システム概要

## 1. システム名

Frichy

## 2. システム目的

Frichy は、フリーランス人材と営業担当者をつなぐ案件管理・応募管理・面談調整・チャット連絡のためのWebシステムである。

求職者はプロフィール、スキル、希望条件、レジュメ、面談候補を登録し、条件を満たした後に案件を検索・応募できる。営業担当者は案件登録、候補者検索、選考ステータス管理、スカウト、稼働確認、面談調整を行う。

## 3. 利用者ロール

| ロール     | 説明               | 主な操作                                                                                                                                       |
| ---------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| freelancer | フリーランス求職者 | 会員登録、ログイン、プロフィール登録、レジュメ登録、案件検索、応募、面談候補登録、チャット、匿名スキルシート表示                               |
| sales      | Frichy担当   | ログイン、ダッシュボード確認、案件登録、案件公開/非公開、優先表示切替、候補者検索、応募ステータス変更、スカウト、面談確定/再調整、稼働確認送信 |

## 4. 主要機能

| 機能領域         | 概要                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| 認証             | メールアドレス・パスワードによる登録/ログイン、JWTによるAPI認証                                |
| プロフィール     | 求職者の基本情報、スキル、希望単価、稼働開始日、リモート条件、レジュメ情報、誓約同意を管理     |
| 案件管理         | 営業が案件を登録し、必要スキル、歓迎スキル、単価、リモート条件、優先表示、公開状態を管理       |
| 案件検索・応募   | 求職者が公開案件を検索し、応募を作成                                                           |
| 選考管理         | 応募ステータスを「選考中」「面談待ち」「成約」「見送り」で管理し、履歴を保存                   |
| 面談調整         | 求職者または営業が面談候補を登録し、営業が確定/再調整に更新                                    |
| チャット         | 求職者と営業のメッセージ送受信、ブラウザ通知/Web Push通知                                      |
| スカウト         | 営業が候補者にスカウトメッセージを送信                                                         |
| 稼働確認         | 営業が更新停滞・稼働不可状態の求職者を対象に確認バッチを作成                                   |
| 匿名スキルシート | 求職者の公開用スキルシートを匿名化して表示し、専用PDFとして出力                               |

## 5. 求職者の案件閲覧条件

求職者が案件一覧を閲覧するには、以下のプロフィール要件を満たす必要がある。

- 氏名
- メールアドレス
- 電話番号
- 職種/ロール
- 経験年数
- 希望単価
- 稼働開始日
- 稼働率
- リモート条件
- 稼働状況
- スキル
- 最新レジュメ
- 面談候補
- 誓約同意日時

要件未達の場合、APIは `PROFILE_REQUIREMENTS_INCOMPLETE` を返し、画面上では案件閲覧ロック状態になる。案件閲覧条件を満たした求職者は、初回面談の完了前でも案件応募と営業とのチャットを利用できる。初回面談完了は案件ごとの面談候補登録にのみ必要とする。

- Webフロントエンド
- REST API
- PostgreSQLデータベース
- Prismaによるデータアクセス
- JWT認証
- 個人情報暗号化
- Web Push通知
- ローカル開発用Docker Compose

- 本番インフラ構成
- CI/CD構成
- ファイル本体のアップロード先実体
- 監査ログ基盤
- メール通知
- 権限ロールの細分化
- 決済・請求・契約書管理
